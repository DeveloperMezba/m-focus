# M Focus (Android)

Kotlin + Jetpack Compose. Open this folder in Android Studio, let Gradle sync, then Build > Build APK(s).
Install the APK on the phone, open M Focus and follow the two setup cards.

Android 13+: for a sideloaded app the accessibility switch is greyed out ("Restricted setting").
Fix: Settings > Apps > M Focus > top-right menu (three dots) > "Allow restricted settings", then enable accessibility.

Three things are asked once: Accessibility, Notification access, Battery optimization. Both Accessibility and Notification access need "Allow restricted settings" on Android 13+.
